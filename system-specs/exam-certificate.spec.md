# Экзамен и сертификат — черновик контура

> Статус: заметка по итогам обсуждения (авг 2026). Не реализовано; фиксирует решения
> владельца продукта, чтобы следующие фазы отталкивались от них.

## Решения владельца

- **Оффлайн-first — только для обучения.** Всё, что вне вкладки «Интернет», играется без сети:
  квесты, уроки, результаты копятся локально и расходятся синхронизацией (частота настраивается,
  у профиля отдельный, более редкий график). Целостностью оффлайн-результатов сознательно
  жертвуем.
- **Компенсация — античит по статистике.** Вместо доверия каждому оффлайн-попытке система будет
  сверять косвенные признаки активности (динамику ответов, тайминги, паттерны между попытками).
  Конкретные метрики — предмет отдельной спецификации.
- **Онлайн-only режимы:** турниры и **экзамен**. Это другая логика (другой модуль), попытки идут
  только при живом соединении и верифицируются сервером.
- **Экзамен — структурная точка:** последний урок в теме → выпускной экзамен темы;
  последняя тема раздела → экзамен раздела; последний раздел квиза → экзамен квиза.
- **Сертификат** выдаётся после прохождения выпускного экзамена верхнего уровня (квиза).

## Открытые вопросы (к следующей спеке)

1. Где живёт экзамен в домене: отдельная сущность или флаг у `Lesson`/`Theme`?
2. Что именно проверяет сертификат и где хранится (Firestore-документ, изображение, UUID)?
3. Какие метрики античита считаем на клиенте, какие выводим только на сервере?
4. Пересдачи: срок блокировки, цена (жизни/нолики), влияние на сертификат.
5. Связь с турнирами: влияет ли рейтинг экзаменов на посев турнирных сеток.

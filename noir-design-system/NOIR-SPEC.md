# NOIR — єдина дизайн-система (канонічна специфікація)

> Це **єдине джерело правди** для всіх портів (Android XML, Compose, HTML, нові застосунки).
> Перед будь-якою генерацією екрана — прочитай цей файл і **транскрибуй** його, не виводь з пам'яті.
> Дата фіксації: 2026-08-18. Заблоковані вибори: поверхні `soft`, акцент `azure`, заголовок `glowbar`, перемикач `switch`, група `hairline`, тема `daynight`.

---

## 1. Характер бренду (одним реченням)

Інженерна темрява на чистому чорному: широкий технічний гротеск, моно-числа, hairline-структура і рідкісні рольові ефекти — SpaceX/Bloomberg, а не «різнобарвна дитяча гра».

## 3. Акцент і статуси

| Роль | Hex | Значення |
|---|---|---|
| `accent` | `#0599EF` | **єдиний** акцент (азure). Hue зсунуто від Google Blue. |
| `gold` | `#FFD700` | Pro / преміум |
| `success` | `#5CC97A` | успіх / легкий режим |
| `danger` | `#F0564B` | помилка / деструктив / складний режим |
| `violet` | `#9680F2` | лімітоване / сезонне |

Правило акценту: **один акцент, максимум 2 рази на екран** (кікер + головна дія).

## 4. Типографіка

| Роль | Шрифт | Параметри |
|---|---|---|
| Display / заголовки | Archivo **SemiExpanded** (wdth≈112), 600–700 | uppercase, tracking `+.06…+.22em` |
| Body | system-ui / Roboto 400–500 | звичайний регістр |
| Mono (числа/таймери/ціни/кікери/кнопки) | JetBrains Mono 500–700 | `tabular-nums` |

Розміри: display 28, title 20–22, headline 16, body 14, caption 12, mono 12–13.

**Важливо:** кнопки — це **mono**, НЕ Archivo. Archivo — тільки для заголовків/display.

## 5. Радіуси, відступи, розміри

- Радіуси: `8 / 12 / 16 / 20 / 999(пігулка)`. Картки — 16, кнопки — 12, діалоги/sheet — 20, чипи — пігулка.
- Відступи: база 4dp (8 / 12 / 16 / 24 / 32).
- Тач-цілі: ≥44dp (кнопки 48dp). Ряди списку min-height 56dp.

## 6. Компоненти (обов'язкові, 1:1)

### 6.1 Кнопка `.btn`
- Шрифт **JetBrains Mono**, 12sp, weight 700, **uppercase**, letter-spacing `.12em`.
- Радіус 12, min-height 48, padding 13/18.
- Варіанти:
  - **primary** — фон accent `#0599EF`, текст ink `#05090F`.
  - **ghost** — фон surface-3, обводка outline, текст text-1.
  - **gold** — прозорий, обводка gold×52%, текст gold.
  - **done** — фон surface-2, обводка success×45%, текст success.
  - **disabled** — фон surface-2, текст text-off (єдиний дозволений низький контраст).
- Правило: **одна primary-кнопка на екран/дію**; поруч — тільки одна залита.

### 6.2 Група `.group` (hairline-блок, НЕ плаваюча картка)
- Обводка `hair`, радіус 16, фон surface-1, `top-light` кромка, `overflow hidden`.
- Внутрішні розділювачі між рядками — `hair`.

### 6.3 Секційний заголовок `.gt` (плашка, НЕ кутова дужка)
- Повна ширина: **іконка 18dp** (тонована роллю) + **жирний титул 13.5sp** кольором ролі.
- Фон — градієнт `role×16% → surface-2 55%` (зліва направо).
- Обводка `hair`, радіус 12, padding 13/15.
- Ролі: accent (дефолт), gold, violet, danger — через одну змінну `--gt-c`.

### 6.4 Перемикач `.sw` (світч, НЕ чекбокс)
- 48×28 пігулка, фон surface-4 + inset-обводка outline.
- **on** — фон accent + світіння `0 0 18px accent×38%`, повзунок ink.
- Використовується для on/off-налаштувань. (Чекбокс — лише для множинного вибору.)

### 6.5 Чип `.chip`
- Mono uppercase 10sp, letter-spacing `.12em`, пігулка, обводка hair, фон surface-2.
- Ролі: gold / violet / success / accent — колір тексту + обводка + фон×10%.

### 6.6 Рядок списку `.row`
- Іконка-плитка `ri` (34dp, радіус 10, фон surface-3) + назва 13.5sp (text-1) / підпис 12sp (text-3) + значення `rv` (mono 12, text-3) + шеврон.
- min-height 56, padding 13/16, розділювач `hair`.

### 6.7 Поле вводу
- Фон surface-2, обводка outline; фокус — accent.

## 7. Рольова система ефектів (бюджет: **максимум 2 на екран**)

| Ефект | Роль | Ліміт |
|---|---|---|
| Золотий контур + sheen-блиск (7с) | Pro / преміум | 1 картка на екран |
| Фіолетовий контур + світіння | лімітоване / сезонне | 1 на екран |
| Акцентне світіння `0 0 18px` | активна дія, фокус, обране | тільки головна дія |
| Radial-світіння режиму (синій/зелений/червоний) | контекст гри | фон екрана питання |

Ефект = **роль**, не декор. Без ролі — ефекту немає.

## 8. Анти-патерни (заборонено)

- Фіолетовий/веселковий градієнт як фон.
- Емодзі замість іконок.
- Archivo на кнопках (кнопки = mono).
- Кутові дужки як заголовок секції (це `.gt`-плашка).
- Чекбокс для on/off (це світч).
- Плаваючі «надуті» картки з тінню (це hairline-блоки).
- Hover/фокус, що робить текст сірішим або світлішим.
- Більше одного залитого primary-кнопки на дію.
- Вигадані метрики / порожні картки-заглушки.

## 9. Чеклист приймання (P0 — обов'язково)

- [ ] Усі кольори — лише з токенів розділу 2–3 (жодних raw hex поза системою).
- [ ] Кнопки — mono uppercase, tracking `.12em`.
- [ ] Заголовки секцій — `.gt`-плашка з іконкою, не дужка.
- [ ] on/off — світч, не чекбокс.
- [ ] Групи — hairline-блоки, не плаваючі картки.
- [ ] Числа/час/ціни — mono + tabular-nums.
- [ ] Контраст: текст ≥4.5:1, великий текст/іконки ≥3:1 (виняток — тільки disabled).
- [ ] Тач-цілі ≥44dp.
- [ ] ≤2 ефекти на екран, кожен із роллю.
- [ ] Один акцент на екран, максимум 2 застосування.

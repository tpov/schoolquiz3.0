# Pipeline Gate Ledger

Реестр срабатываний гейтов пайплайна. Заполняется ретроспективой (`feature-retrospective`, Фаза 1.2.5),
читается на Фазе 3.5 (обрезка).

**Зачем**: пайплайн, который умеет только добавлять проверки, монотонно растёт в стоимости.
Этот файл — единственный источник данных, позволяющий обоснованно убрать лишнее.
Правило: **нет статистики — не режем**.

## Гейты, не подлежащие обрезке никогда

Независимо от статистики — это защита от необратимого:

- `security-reviewer` и всё, что касается auth / privacy / credentials / exported surface
- всё, что защищает от потери данных: `Test Deletion Gate`, проверки Room-миграций
- необратимые операции: миграции хранилища, внешние платежи/стоимость
- `grounding Independent Verification` — несущая конструкция против галлюцинаций (её отказ не виден в статистике: она предотвращает баги, а не ловит их)

## Чем отличается от v1
v1 моделировал команду лида статическим граф-веером. v2 воспроизводит механику источника:
- research: N субагентов = N search criteria (без ограничения) + core-scan на пакет;
- plan: planner возвращает разбиение по вертикалям, лид поднимает доп. раны роли planner;
- design: спор двух архитекторов через relay + cross-model линзы последовательно по группам документов;
- implement: **билд гоняет сам coder, он же поднимает ревьюеров и крутит автономный цикл reviewer↔coder;
  лид пассивен**; владелец ревью фазы — backend-dev (или frontend-dev в чисто фронтовой фазе);
  масштабирование = повторный ран той же роли;
- debug: состав Phase 2 по diagnostics-proposal; прямой фикс = dev + test-dev + обязательный code-reviewer.

## НЕ ПРОВЕРЕНО (нужен рабочий лимит OpenAI)
Вложенный спавн: субагент поднимает субагента (`kent run --agent` из сессии coder-а).
На этом держится автономный цикл reviewer↔coder. В промптах есть детерминированный фолбэк:

и ревьюеров поднимает лид. Проверить первым же прогоном.

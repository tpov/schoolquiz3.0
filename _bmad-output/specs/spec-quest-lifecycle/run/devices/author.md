# Жизненный цикл квеста: роль АВТОР (17e6bcfc)

## Резюме

Исследовал, как автор отправляет квест на проверку. Найденное поведение:
- Квест можно отправить на арену кнопкой "Отправить на арену"
- Кнопка является рабочей и обрабатывается (выполняется действие)
- Однако результат действия —  "Квест на арену поставлен в очередь", а не "отправлен на проверку"
- Кнопка "Сохранить" в форме создания квеста не реагирует на нажатие
- Пути явной отправки на проверку (с статусом "отправлен на проверку") не найдены в текущем UI

## Выводы и несоответствия

### Найденное поведение vs. Playbook

**Playbook (device-run-playbook.md, раздел 2)** ожидает:
```
./scripts/devices/ui.sh $S tap "арену"
# Ожидаемо: статус черновика сменился на «отправлен на проверку»
```

**Реально найдено:**
- Кнопка "Отправить на арену" существует и работает
- Результат: "Квест на арену поставлен в очередь"
- Статус квеста в "Мои квесты" остаётся "Черновик" (не меняется на "отправлен на проверку")

### Открытые вопросы

1. **Разница между "отправить на арену" и "отправить на проверку":** 
   - Playbook говорит о статусе "отправлен на проверку" 
   - Текущий UI показывает только "отправить на арену"
   - Возможно, это две разные функции или фичи ещё не реализованы

2. **Кнопка "Сохранить" неработающая:**
   - XML показывает clickable="false"
   - Возможно, требуется определённое состояние формы для активации

3. **Нет явного UI для отправки на проверку:**
   - Раздел "Проверка" в меню — это просмотр задач проверяющими, не отправка от автора
   - В "Мои квесты" нет контекстного меню с опциями отправки

## Итог исследования

Найден один рабочий путь отправки квеста: нажатие кнопки "Отправить на арену". 
Однако результат этого действия — отправка на арену для соревнований, а не отправка на проверку. 

Явного UI для отправки на проверку (с ожидаемым статусом "отправлен на проверку" из playbook) не найдено. 

**Возможные варианты:**
- Фичу отправки на проверку ещё не реализовали в текущей версии
- Отправка на арену и отправка на проверку — одно и то же действие (кнопка / сообщение просто неправильно названы)
- Есть другой путь отправки на проверку, который требует дополнительных действий или других условий

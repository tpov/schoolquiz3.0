Conservation still holds (whatever was charged burns, 4.25 manifest) — the defect is tariff evasion, not money non-conservation.
- **L-new-2 [fix-now, small] Apply churn and a dead expression in `applyCopyEditProposal`.** (a) The write loop iterates **all** validated questions with version bumps and sync-changes per question (`index.js:6124-6136`), including byte-identical ones — inflated question versions and player-side sync churn for untouched questions; `mergedQuestionsForApply` already returns the changed subset.

# Вклад в SchoolQuiz

Спасибо, что хотите внести вклад в этот проект! Мы приветствуем любые улучшения, багфиксы, новые функции и предложения.

## Как внести вклад

1. **Fork** репозиторий и создайте свою ветку:
   ```bash
   git checkout -b feature/ваша-фича
   ```
2. Внесите изменения, добавьте тесты и убедитесь, что проект собирается локально:
   ```bash
   ./gradlew assembleDebug
   ./gradlew testDebugUnitTest
   ./gradlew detekt
   ./gradlew ktlintCheck
   ```
3. Сделайте commit и push в свой fork:
   ```bash
   git commit -am 'Добавил новую фичу'
   git push origin feature/ваша-фича
   ```
4. Откройте Pull Request в ветку `master` оригинального репозитория.

## Кодстайл и проверки
- Используйте существующий стиль кода (Kotlin, TypeScript).
- Все изменения должны проходить проверки detekt и ktlint (Kotlin) или eslint/prettier (TypeScript, если настроено).
- Не забывайте про документацию и комментарии к коду.

## Тесты
- Для новых функций и багфиксов пишите unit-тесты.
- Все тесты должны проходить (`./gradlew testDebugUnitTest`).

## Firebase Functions
- Новые функции добавляйте в `functions/src/` и экспортируйте в `functions/src/index.ts`.
- Проверяйте сборку функций локально: `npm run build` в папке `functions`.

## Сообщения об ошибках и предложения
- Описывайте баги и фичи максимально подробно.
- Прикладывайте логи, скриншоты и шаги для воспроизведения.

## Контакты
- Если есть вопросы — создайте issue или напишите автору.

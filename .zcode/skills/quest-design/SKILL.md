# Дизайн квеста

Роль: методист предмета. Результат — 140 файлов `data/school/<subj>/focus/<s>-<t>-<l>.json` и согласованный силлабус.

## Шаг 1 — исследование (до предложения)
- Прочитать `data/school.js` и существующие `data/school/*/syllabus.js`: чего уже есть, чтобы не дублировать.
- Если пользователь дал материал (файлы, ссылки, учебник) — построить курс ВОКРУГ него: разделы и темы по его оглавлению, факты и примеры из него.
- Определить рамку: аудитория (обычно «полный школьный курс до уровня выпускника 11 класса», сложность нарастает), язык (RU), нейтральность (история — всемирная, факты вместо оценок; география — без политических суждений о странах, экономика «порядка», а не цифры года).

## Шаг 2 — силлабус (СТОП: согласовать с пользователем)
Предложить таблицу 7 разделов × 4 темы с названиями и одной строкой «что внутри». Разделы сквозные, от базового к выпускному. Дождаться «да» или правок. Без согласования спеки не писать.

## Шаг 3 — спеки
Для каждой темы ровно 5 уроков — прогрессия без пересечений. Один файл на урок, строгий JSON:
```json
{ "coords": {"s":7,"t":4,"l":2}, "sectionTitle": "…", "themeTitle": "…", "lessonTitle": "…",
  "focus": "одно предложение — чему учит урок",
  "teaching_points": ["5–9 конкретных утверждений/умений"],
  "key_facts": ["даты, числа, определения — ТОЧНЫЕ, это опора автора"],   // или "formulas" для точных наук
  "example": "конкретный разбор задачи/примера с ответом",
  "level": "базовый | профильный | выпускной" }
```
Требования к спекам: определения верны дословно; в `key_facts`/`formulas` — то, что автор будет пересчитывать; отметить типичные ошибки учеников (они станут дистракторами); картинок нет — геометрию/графики/карты описывать словами.

## Шаг 4 — проверка и сборка
- `ls data/school/<subj>/focus | wc -l` → 140; каждый файл парсится как JSON.
- Новый предмет: добавить в `META` файла `_build-school-syllabus.js` (`id: 'qb-school-<subj>'`, `idBase: 'school-<subj>'`, `title`), создать `data/school/<subj>/_helpers.js` копией существующего с заменой префикса `qsb-school-<subj>-`, и `data/school/quest-<subj>.js`.
- `node _build-school-syllabus.js <subj>` → `lessons=140/140 OK`.

Параллелизм: 1 субагент = 1 раздел (20 спек). Итог отчёта: «<subj> S<n>: 20 files».

# Авторинг темы

Тебе поручена ОДНА тема `<s>-<t>` предмета `<subj>` — уроки `<s>-<t>-1 … -5`.

## Шаг 0 — что уже есть (никогда не переписывать готовое)
`node progress.js <subj>` — файлы с 40 вопросами НЕ ТРОГАТЬ, писать только недостающие.

## Шаг 1 — спека
Прочитать `data/school/<subj>/focus/<s>-<t>-<l>.json` и строить урок СТРОГО вокруг `focus`, `teaching_points`, `key_facts`/`formulas`, `example`. Точность фактов и чисел критична; в `info` показывать ход решения.

## Шаг 2 — файл урока `data/school/<subj>/lessons/<s>-<t>-<l>.js`
```js
'use strict';
const { sc, mc, ord, fb, op4, op5, op6, items4, items5, cand5 } = require('../_helpers');
module.exports = [ /* ровно 40 вопросов */ ];
```
Сигнатуры:
- `sc(i,'EASY'|'HARD','вопрос?', op4('A','B','C','D'), 'a', 'инфо')` — ровно ОДИН верный.
- `mc(i,diff,'вопрос?', op5(...)|op6(...), ['a','c','e'], 'инфо')` — ≥2 верных; каждый невыбранный однозначно неверен.
- `ord(i,diff,'Расположите … по порядку.', items4(...)|items5(...), 'инфо')` — пункты в ПРАВИЛЬНОМ порядке; признак сортировки один и однозначный.
- `fb(i,diff,'текст с ___', [{id:'b1',correctCandidateId:'c3'}], cand5('в1','в2','в3','в4','в5'), 'инфо')` — 4-й аргумент ОБЯЗАТЕЛЬНО массив blanks; `cand5` ровно 5; число `___` в тексте = числу blanks.

Порядок индексов 0..39 СТРОГО: 5 sc EASY, 5 sc HARD, 5 mc EASY, 5 mc HARD, 5 ord EASY, 5 ord HARD, 5 fb EASY, 5 fb HARD.

## Правила качества (главные источники дефектов)
1. **Нет второго верного.** Численно проверяй неэквивалентность дистракторов (6√3 vs 10,39; 0,5 vs 1/2 vs 50 %; 36 км/ч vs 10 м/с); для утверждений — «неверный» вариант не должен быть истинным при буквальном чтении; не давать достаточное условие вместо единственного.
2. **Никаких позиционных ссылок в `info`** («первый вариант», «два последних», «вариант б», «третий шаг», «соответственно») — раннер тасует варианты. Писать по содержанию: «запись 2NaOH + H₂SO₄ → …».
3. **Ordering однозначен:** никаких взаимозаменяемых шагов, параллельных ветвей «если А / если Б», симметричных расчётов; каждый шаг опирается на результат предыдущего; пункт не ссылается на соседний («сделать то же для анионов»). Естественно упорядоченные ряды (годы, величины) записывать по возрастанию/хронологии.
4. **FillBlank:** подставь каждый кандидат в текст — верен ровно один; кандидаты не синонимы друг друга.
5. **Дистракторы взаимоисключающие** и того же уровня детальности, что ключ (ключ не должен выдавать себя длиной или пояснением в скобках).
6. **Без дублей** внутри темы: сравни все 200 вопросов по смыслу.
7. **Согласованность:** общие утверждения не противоречат задачам того же урока; алгоритмы в разных ord одного урока не противоречат друг другу.
8. Ключи по позициям НЕ выравнивать (раннер тасует). Тон нейтральный (история/география — факты без оценок). Картинок нет — описывать словами.

## Шаг 3 — самопроверка
`node gate-lesson.js <subj> <s>-<t>` до `GATE: CLEAN`. Для точных наук дополнительно пересчитать все ответы независимым скриптом (node), не доверяя своему `info`.

Отчёт: какие уроки написаны, что пересчитано, вывод гейта.

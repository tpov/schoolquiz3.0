Репозиторий проекта: /Users/tpov/schoolquiz3.0 — сначала выполни `cd /Users/tpov/schoolquiz3.0/scripts/seed-bulk` и загрузи скиллы quest-pipeline и quest-audit. Работай автономно, вопросов пользователю не задавай — все решения уже приняты ниже. Объём: $ARGUMENTS (пусто = all).

ЭТАП 0 — состояние. `node progress.js --all`; `git status --porcelain data/school | head`. Если в рабочем дереве уже есть незакоммиченные правки уроков — не откатывай их, это результат предыдущих прогонов.

ЭТАП 1 — дубли в залитых предметах (если объём all или dups). Для каждого предмета из math, physics, chemistry, biology, geography выполни `node gate-lesson.js <subj> --all | grep ДУБЛЬ`; собери список тем `<s>-<t>` с дублями. Для каждой такой темы запусти ОТДЕЛЬНОГО субагента с заданием «Ты ревизор. Прочитай скилл quest-audit целиком и проведи аудит темы <subj> <s>-<t> по нему; в первую очередь устрани дубли (второй экземпляр переписать на другой материал того же урока, тип/сложность/позиция сохраняются); закончи `node gate-lesson.js <subj> <s>-<t>` → GATE: CLEAN; верни отчёт по категориям». Запускай субагентов волнами по 4–6 параллельно. После каждой волны сам проверь гейт темы.

ЭТАП 2 — история (если all или history). 28 тем `1-1 … 7-4`, по одному субагенту на тему, волнами по 4–6 параллельно, задание — как в этапе 1, плюс: «всемирная история — даты и факты проверять, тон нейтральный, никаких оценок». В промпт каждой следующей волны добавляй список классов дефектов, найденных предыдущими темами.

ЭТАП 3 — география (если all или geography). То же самое для geography.

ЭТАП 4 — сборка и отчёт. `node gate-lesson.js history --all | tail -1`, `node gate-lesson.js geography --all | tail -1`, `node format-for-firebase.js data/school/quest-history.js`, `node format-for-firebase.js data/school/quest-geography.js` — ждём ALL INVARIANTS OK. Затем `cd /Users/tpov/schoolquiz3.0 && git add scripts/seed-bulk/data/school && git commit -m "quests: аудит истории и географии, дубли в залитых предметах (ZCode, Weekend Build)"` — БЕЗ push. Итоговый отчёт: таблица тем × категорий дефектов, что не удалось починить, время и токены. В Firebase НЕ заливать — это отдельная команда /quest:seed по явному слову пользователя.

Правила на весь прогон: не переписывать уроки, у которых гейт чист и дефектов не найдено; временные файлы — с уникальными именами; если субагент упал — перезапустить его на ту же тему, не более трёх раз.
